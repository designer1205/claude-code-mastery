# 개발자 웹 이력서 로드맵

## 1. 프로젝트 개요

- **목표**: 반응형 1페이지 개발자 이력서(포트폴리오) 웹사이트 제작
- **기술 스택**
  - HTML5 (시맨틱 마크업)
  - CSS3 (커스텀 스타일 보완)
  - Tailwind CSS (CDN 방식, 별도 빌드 도구 없음)
  - Vanilla JavaScript (ES6+, 프레임워크 없음)
- **특징**: 서버/빌드 없이 `index.html`만 열면 바로 동작하는 정적 사이트

## 2. 폴더 구조 (예정)

```
dev-resume/
├── index.html          # 메인 HTML 파일
├── css/
│   └── styles.css      # Tailwind 보완용 커스텀 CSS
├── js/
│   └── main.js         # 다크모드 토글, 모바일 메뉴, 스크롤 인터랙션
├── assets/              # 프로필 이미지, 아이콘 등
└── ROADMAP.md
```

## 3. 이력서 섹션 구성 (일반적인 내용)

- **Header / Hero**: 이름, 직함(예: Frontend Developer), 한 줄 소개, 프로필 사진, 소셜 링크(GitHub/LinkedIn/Email)
- **About**: 간단한 자기소개 문단
- **Skills**: 기술 스택 뱃지/아이콘 그리드 (언어, 프레임워크, 툴)
- **Experience**: 경력 타임라인 (회사, 기간, 직무 요약) — 플레이스홀더 데이터
- **Projects**: 프로젝트 카드 (제목, 설명, 기술 태그, 링크) — 플레이스홀더 2~3개
- **Education**: 학력 / 자격증
- **Contact**: 이메일, 소셜 링크, (선택) 간단한 문의 폼
- **Footer**: 저작권, 맨 위로 가기 버튼

## 4. 개발 단계

### Phase 1 — 기획
- [ ] 섹션별 콘텐츠 초안 작성 (이름, 소개, 경력, 프로젝트 등)
- [ ] 전체 레이아웃 와이어프레임 스케치

### Phase 2 — 프로젝트 셋업
- [ ] 폴더/파일 구조 생성 (`index.html`, `css/`, `js/`, `assets/`)
- [ ] Tailwind CSS CDN 스크립트 연결
- [ ] 기본 HTML 스켈레톤 작성 (meta, title, favicon 등)

### Phase 3 — 마크업
- [ ] 시맨틱 HTML로 전체 섹션 구조 작성 (`header`, `section`, `footer` 등)
- [ ] 네비게이션 바 및 앵커 링크 구성

### Phase 4 — 스타일링
- [ ] Tailwind 유틸리티로 레이아웃 / 색상 / 타이포그래피 적용
- [ ] 반응형 디자인 적용 (모바일 / 태블릿 / 데스크톱)
- [ ] 다크모드 스타일 준비 (Tailwind `dark:` 클래스)

### Phase 5 — 인터랙션 (JavaScript)
- [ ] 모바일 햄버거 메뉴 토글
- [ ] 부드러운 스크롤 네비게이션 (smooth scroll)
- [ ] 다크모드 토글 버튼 + localStorage 저장
- [ ] (선택) 스크롤 시 섹션 페이드인 애니메이션

### Phase 6 — 콘텐츠 채우기
- [ ] 플레이스홀더를 실제/일반적인 예시 데이터로 채움
- [ ] 프로필 이미지 및 아이콘 삽입

### Phase 7 — 반응형 & 접근성 점검
- [ ] 다양한 화면 크기(모바일/태블릿/데스크톱)에서 레이아웃 확인
- [ ] 이미지 `alt` 텍스트 점검
- [ ] 키보드 내비게이션 및 명도 대비 점검

### Phase 8 — 배포
- [ ] GitHub Pages / Netlify / Vercel 중 택1로 배포
- [ ] 배포 후 링크 및 리소스 경로 최종 점검

### Phase 9 — 향후 개선 아이디어
- [ ] 다국어(한/영) 지원
- [ ] 이력서 PDF 다운로드 버튼
- [ ] 방문자 카운터
- [ ] 스크롤 애니메이션 라이브러리(AOS 등) 도입

## 5. 참고사항

- 초기 개발은 `bucket-list-main` 프로젝트와 동일하게 **빌드 도구 없이 Tailwind CDN 스크립트 태그**로 시작한다.
- 추후 실제 프로덕션 배포나 커스터마이징 확장이 필요해지면 Tailwind CLI/PostCSS 빌드 방식으로 전환을 고려할 수 있다.
